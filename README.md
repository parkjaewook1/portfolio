## 🐾 Featured Project

### Petmily
반려동물과 반려인을 위한 커뮤니티 & 관리 서비스

- 프로젝트 형태: 5인 팀 프로젝트
- 팀 프로젝트 당시 담당: 미니홈피 다이어리 기능
- 프로젝트 종료 후: 기존 인증 흐름·토큰 처리·배포 연결·다이어리 기능을 중심으로 개인 리팩토링 진행
- 개인 리팩토링 주요 내용: Refresh Token DB 검증·기본 Rotation, 권한 값 변환, Axios 401 재발급·재시도, 방명록 부모 참조·재귀 렌더링

📌 상세 내용은 포트폴리오 사이트 내 Project 섹션에서 확인할 수 있습니다.

## 🛠 Tech Stack
- 이 포트폴리오: React, JavaScript, CSS, Chakra UI, Create React App(react-scripts), GitHub Pages
- Petmily Frontend: React, Vite, Axios, Chakra UI
- Petmily Backend: Java, Spring Boot, Spring Security, JWT, MyBatis
- Petmily Database: MariaDB
- Petmily Deploy: Oracle Cloud + Vercel (이미지는 서버 로컬 파일로 저장)
